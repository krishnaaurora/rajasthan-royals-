# AGENTS.md — SupeRR Selector Engine

This project implements Rajasthan Royals SupeRR Selector Season 2:
- Primary goal: Identify Top 10 batters and Top 10 bowlers under pressure.
- Architecture: Modular Monolith + Hexagonal Architecture + Domain-Driven Design.
- Data Pack: 200,999 deliveries, 883 matches, 141 competitions (2022-2026).
- Mathematical Pressure Index ($PI$): Threshold $PI \ge 0.60$ defines the high-pressure crucible.
